# PRD: 室友公約與噪音管理系統

## 1. 專案概述
- **背景與動機**：合租生活中，室友間常因生活習慣差異（如噪音、衛生）、共同開支分攤或物資採買等問題產生摩擦。當面溝通容易傷和氣，且缺乏客觀紀錄。因此需要一個系統來協助制定公約、管理財務與生活瑣事，促進和諧的共居環境。
- **目標用戶**：大學生或跟別人一起合租的人。
- **核心價值主張**：提供一個客觀、中立的平台，讓室友間的約定、開支與提醒透明化，減少直接衝突，維護良好的居住品質與人際關係。

## 2. 功能需求

以下為系統主要功能的使用者故事：

### 1. 共同物資庫存
- **作為** 合租室友，**我希望** 能夠記錄與查看共同物資（如衛生紙、洗碗精）的剩餘數量，**以便** 在快用完時能及時採買，避免無物可用的窘境。

### 2. 公約異動記錄
- **作為** 合租室友，**我希望** 系統能記錄生活公約的制定與修改歷史，**以便** 所有人都能隨時查閱最新共識，減少因為遺忘而產生的爭執。

### 3. 共同開支帳本
- **作為** 合租室友，**我希望** 能夠記錄共同花費（如購買共同物資），系統能自動計算每人應攤提的金額與當前結餘，**以便** 公平且清楚地管理合租財務。

### 4. 友善黑臉
- **作為** 怕傷和氣的室友，**我希望** 能透過系統發送匿名的提醒（如降低音量或清理公共區域）給特定室友，**以便** 在不破壞關係的前提下，反映生活上的困擾。

### 5. 隱形管家
- **作為** 忙碌的合租室友，**我希望** 系統能自動定期發出生活庶務（如倒垃圾、繳費、值日生打掃）的通知，**以便** 讓「系統」來當管家，避免總是由同一個人催促大家而感到疲憊。

### 6. 智慧電費
- **作為** 合租室友，**我希望** 能輸入每期電費帳單與各房間獨立電表度數，系統能自動計算並分攤公共電費與個人電費，**以便** 輕鬆且準確地結算每個人應繳的電費。

## 3. 非功能需求
- **技術限制**：
  - 後端架構：Flask
  - 前端模板：Jinja2
  - 資料庫：SQLite
- **效能與安全考量**：
  - 系統需具備基礎的使用者註冊與驗證機制（Login / Logout），確保同一租屋處的群組隱私安全。
  - 預防常見的網頁攻擊（如 CSRF、SQL Injection 等）。
  - 介面需採響應式設計（RWD），確保在行動裝置（手機）上有良好的操作體驗，符合多數大學生與年輕族群的使用習慣。

## 4. MVP 範圍 (Minimum Viable Product)

### Must Have (必須要有)
- 基礎的帳號與租屋群組建立系統。
- 共同開支帳本（基本記帳與每人應付金額計算）。
- 友善黑臉（發送匿名通知功能）。
- 公約異動記錄（建立與展示文字版公約與修改歷史）。

### Should Have (應該要有)
- 智慧電費（能輸入獨立電表度數與總帳單進行分攤計算）。
- 隱形管家（設定簡單的週期性打掃/倒垃圾提醒）。

### Nice to Have (有了更好)
- 共同物資庫存（進銷存功能，甚至結合開支帳本）。
- 第三方通訊軟體整合（例如串接 LINE Notify，將提醒直接發到群組）。
